# 柴务 / ChaiWu

个人本地财务工具，包含 SwiftUI iPhone 客户端和 WPF Windows 客户端。两个客户端分别默认使用 iCloud Drive 和 OneDrive 文件路径；共享账单需要另行配置同一个文件来源。

## iPhone 账单操作

- 新增：右上角 `+`，可选择任意账单日期；补录 9 月的账单时选 9 月日期。
- 编辑：进入对应月份，点击账单；累计收支及广告明细也可点开编辑。金额、类型、分类、备注、日期均可修改。
- 删除：左滑明细，或进入编辑页点击「删除这条账单」。同步保存删除标记，旧快照不会恢复已删除记录。
- 分类：右上角齿轮 → 设置 → 收支分类，分别管理收入、支出选项；点击改名，左滑移除，或添加新分类。移除分类不删除旧账单，改名保留统计身份。分类名称设置保存在本机。
- 月份归属以账单日期为准，编辑日期后即时刷新列表及统计。

## 旧同步文件

旧版曾将不含 UUID 的六列分享表写作同步文件，无法可靠识别原账单。新版会暂停合并这种文件，避免重复导入或覆盖修改。

先核实需要保留的记录已在本机，再进入设置点击「备份并重建旧同步文件」。重建将先备份原文件，随后写入本机数据库记录及完整同步标识；备份失败停止重建。云端独有账单需要先人工核对或导入。历史重复账单不会自动清理。

普通「导出表格」仍生成六列可读报表，使用完整年份及日期，不会覆盖同步文件。分享报表没有 ID，手动导入会新增记录。

本次修复针对 iPhone；旧 Windows 客户端不支持自定义分类和删除标记，不应与新版同步表混用。

## 验证和构建

最低 iOS 16.0。沿用仓库内 `iOS/ChaiWu.xcodeproj`，没有 XcodeGen 配置。

macOS 数据层回归验证：

```sh
bash scripts/test-ios-data.sh
```

修复分支 GitHub Actions 执行回归测试及无签名 iPhone archive，产物名 `ChaiWu-iOS-repair`；下载其中 IPA，用 TrollStore 覆盖安装同一 App，以保留现有数据库。
